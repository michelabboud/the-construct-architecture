# 02 — Oracle & XP System

Extends the basic example with Oracle judgment, XP tracking, and the level-up system.

## What It Shows

```
Worker output → Oracle judges → XP awarded → Level-up check → Agent profile updated
```

## Run It

```bash
npx tsx examples/02-oracle-xp/index.ts
```

## Key Concepts

- **Oracle** — judges work quality, awards XP, tracks agent performance
- **XP System** — positive-only rewards (good work earns XP, bad work earns 0)
- **Level-Up** — agents progress through rookie → reliable → trusted → expert
- **Agent Profiles** — persistent records of an agent's performance history
